# Smart Automatic Hand Sanitizer Dispenser using Arduino with Multi-Sensor Validation

This project is a touchless sanitizer dispensing system using Arduino that detects and validates a human hand using multiple sensors before dispensing sanitizer. It ensures hygiene and prevents false triggering by checking distance, motion, and warmth, and then activates a servo motor to press the pump while displaying status on an LCD.

## Sensors Used
- Ultrasonic Sensor  
- IR Sensor  
- PIR Sensor  
- Digital Temperature Sensor
